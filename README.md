# Microsoft Intune Lab (Documentation-First)

## Overview
This repository documents my hands-on study of Microsoft Intune using a documentation-first approach, similar to how changes are planned and validated in MSP and enterprise environments.

The goal of this lab is to:
- Gain practical experience with endpoint enrollment and management
- Practice writing clear documentation before and after implementation
- Build repeatable, supportable workflows for device management

## Lab Environment
- Microsoft 365 test tenant
- Windows test VMs for enrollment

## Scope
This lab focuses on:
- Windows device enrollment
- Compliance and configuration policies
- Application deployment
- Basic troubleshooting and remediation

## Methodology
For each task:
1. Define the objective
2. Document the intended configuration
3. Implement changes in a test tenant
4. Validate results
5. Document issues and fixes

## Status
🚧 In progress — actively building and documenting Intune workflows.

## Disclaimer
All work is performed in a test tenant using non-production systems.
